**Based on video-use by Browser Use (MIT).** https://github.com/browser-use/video-use
- `scripts/pack_transcripts.py` and `scripts/timeline_view.py` are video-use files, code unchanged.
- `scripts/transcribe.py` is video-use's `transcribe.py` + `transcribe_batch.py`, merged, with a
  dry-run mode and the API key looked up next to the skill.
- `scripts/build_cut.py` and `scripts/render.py` follow video-use's pipeline (per-segment extract,
  lossless concat, 30 ms fades, captions last) and use its HDR tone-mapping chain (PQ footage).
