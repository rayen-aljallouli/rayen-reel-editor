# edit/project.md

The memory of a reel. Append one section per session and one line per feedback round. Read it
first when the user comes back; summarise the last session in one sentence.

```markdown
## Session 1 — 2026-10-17

**Strategy:** one paragraph: what the reel is, sources, chosen shape, target length.
**Takes:** HOOK IMG_01 @7.30 (take 2: take 1 stumbles) · POINT @41.20–56.98 (one take) · CTA @241.94 (last of four)
**Settings:** speed 1.06 · max_gap 0.35 · zoom centre (0.5, 0.4) · grade none · captions karaoke, accent #E9C46A
**Decided myself:** list every choice the user did not make (they read this list).
**Render:** preview_v1.mp4, 47.3 s, 18 cuts, −16.0 LUFS / −1.6 dBTP, qc clean.
**Outstanding:** open questions, things waiting for the user.

**Round 1 (2026-10-17):** feedback in one line → what changed → preview_v2.mp4 (numbers).
**Round 2 (2026-10-18):** …
**Final (2026-10-18):** final_v1.mp4, 46.8 s, −16.0 LUFS / −1.4 dBTP.
```

Rules:
- Times in the log are source times for takes and output times for overlays; say which.
- Note every number that would be painful to rediscover (A/V offset, crop centre, a grade).
- When the user asks to undo a round, find the version in the log and its file; do not rebuild
  from memory.
